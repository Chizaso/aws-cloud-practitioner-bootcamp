1. Clouding Computing is the delivery services like storage, Networking, servers, databases etc via internet.
   
3. IaaS vs PaaS vs SaaS
   a - IaaS (Infrastructure as a service). It virtualised computing resources e.g Storage, databases and Networking
   b - PaaS (Platform as a service). It provides the platform to OS, middleware and Dev tools
   c - SaaS (Software as a service). It's the ready to use application.
   
4. Cloud VS On-premises
   a - On cost cloud is a subscription/pay-as you go while On-premiese you have to have a large hardware/software purchase
   b - On scalability Cloud is easy to scale instantly while On-premises is linited to physical hardware.
   c - Cloud has a less direct control while On-premises has a full control on infrastructure
   d - you can access Cloud anywhere anytime via internet while On-premises you hace restriction to local area networks and other burdens

5. CapEx vs OpEx in IT
   a - CapEx(Capital Expenditure). That is the large upfront investment in physical assests eg Servers, data centers
   b - OpEx(Operational Expenditure. This is the on-going costs for services, subscription, and usage
